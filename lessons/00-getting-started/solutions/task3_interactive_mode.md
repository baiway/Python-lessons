# Task 3 solution
```console
>>> 60 * 60 * 24
86400
>>> 60 * 60 * 24 * 365
31536000
>>> 2**10
1024
>>> 7 / 2
3.5
>>> 7 // 2
3
```

`/` is normal division, and always gives a decimal answer (even `8 / 2` gives `4.0`). `//` is _integer division_ (sometimes called "floor division"): it divides then rounds _down_ to the nearest whole number. We'll see this again in [Lesson 1](../../01-variables-and-types).
