# IB Diploma Programme
The IB Computer Science course changed for students taking their exams from May 2027 onwards. The details below are from the IB's _Computer science guide_ for the new course, with section numbers in brackets so that you can look them up.

## Assessment
| Component            | What it covers                                                  | SL                                     | HL                                    |
|----------------------|-----------------------------------------------------------------|----------------------------------------|---------------------------------------|
| Paper 1              | Concepts of computer science (theme A), and a pre-seen case study | 1 hour 15 minutes, 50 marks, 35%     | 2 hours, 80 marks, 40%                |
| Paper 2              | Computational thinking and problem-solving (theme B)            | 1 hour 15 minutes, 50 marks, 35%       | 2 hours, 80 marks, 40%                |
| Internal assessment  | A computational solution                                         | 30%                                    | 20%                                   |

- **Language:** there are two versions of Paper 2: one for students who have studied Python, and one for Java. Your school chooses which language you study. Exam questions that include code are written in that language. There's no IB-specific pseudocode, unlike the old course.
- **Built-in functions:** the guide encourages you to use Python's built-in functions like `sort`, `pop`, `len`, `max` and `min` in your own work. But it also says that "certain questions in the examination will prohibit specific built-in functions", so make sure you can write things like a maximum, a search or a sort yourself (as in [Lesson 4](../lessons/04-lists) and [Lesson 10](../lessons/10-searching-and-sorting)).
- **Algorithmic thinking:** one Paper 2 question focuses on algorithmic thinking "without the need to interpret or write code".
- **Case study:** the case study for Paper 1 is published 12 months before the May exams, so that you can research it in advance.
- **Internal assessment:** a "computational solution" to a problem of your own choosing, which takes about 35 hours. You submit up to 2,000 words of documentation (not counting code excerpts, comments or diagrams), and a video of up to five minutes demonstrating your program and how you tested it.

## How the programming content maps onto these lessons
| Topic                                                                                   | Level     | Lessons                                                                 |
|-----------------------------------------------------------------------------------------|-----------|-------------------------------------------------------------------------|
| Variables, substrings, selection, loops, functions and scope (B2.1, B2.3)               | SL and HL | [1](../lessons/01-variables-and-types) to [7](../lessons/07-strings)    |
| Exception handling, "along with the `finally` block" (B2.1.3)                           | SL and HL | [8](../lessons/08-exceptions)                                           |
| Debugging: trace tables, breakpoints, print statements (B2.1.4)                         | SL and HL | [8](../lessons/08-exceptions)                                           |
| 1D and 2D lists; static vs dynamic data structures (B2.2.1, B2.2.2)                     | SL and HL | [4](../lessons/04-lists) and [5](../lessons/05-2d-lists)                |
| Stacks and queues (B2.2.3, B2.2.4)                                                      | SL and HL | [16](../lessons/16-recursion-stacks-and-queues)                         |
| Big O; linear and binary search; bubble and selection sort (B2.4.1 to B2.4.3)           | SL and HL | [10](../lessons/10-searching-and-sorting)                               |
| File processing (B2.5)                                                                  | SL and HL | [9](../lessons/09-files)                                                |
| Classes, objects, constructors, UML class diagrams (B3.1)                               | SL and HL | [11](../lessons/11-classes-and-objects)                                 |
| Static (class) vs non-static (instance) variables and methods (B3.1.3)                  | SL and HL | [11](../lessons/11-classes-and-objects)                                 |
| Encapsulation, information hiding and access modifiers (B3.1.5)                         | SL and HL | The "Encapsulation" and "Properties" sections of [12](../lessons/12-inheritance-and-encapsulation) |
| Recursion (B2.4.4, B2.4.5)                                                              | HL only   | [16](../lessons/16-recursion-stacks-and-queues)                         |
| Inheritance, polymorphism, abstract classes (B3.2.1 to B3.2.3)                          | HL only   | [12](../lessons/12-inheritance-and-encapsulation)                       |
| Composition and aggregation (B3.2.4)                                                    | HL only   | [12](../lessons/12-inheritance-and-encapsulation)                       |
| Design patterns: singleton, factory, observer (B3.2.5)                                  | HL only   | Not covered                                                             |
| Linked lists: singly, doubly and circular (B4.1.2, B4.1.3)                              | HL only   | [18](../lessons/18-linked-lists)                                        |
| Binary search trees (B4.1.4)                                                            | HL only   | [19](../lessons/19-binary-search-trees)                                 |
| Sets, and how hash tables work (`dict` and `set` in Python) (B4.1.5, B4.1.6)            | HL only   | [13](../lessons/13-dictionaries-and-sets) and [20](../lessons/20-hash-tables-and-sets) |

Note that stacks and queues are for everyone, not just HL students, even though they're in the same lesson as recursion.

**In short:** SL students need [Lessons 0 to 11](../README.md#fundamentals), the encapsulation part of [Lesson 12](../lessons/12-inheritance-and-encapsulation), and the stacks and queues part of [Lesson 16](../lessons/16-recursion-stacks-and-queues). HL students also need the rest of Lessons 12 and 16, and [Lessons 18 to 20](../README.md#abstract-data-types).
